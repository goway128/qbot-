把 AI
接入 QQ

一个在 Android 手机上运行的 QQ AI 机器人。Linux 环境、QQ、NapCat 和消息编排都在本地完成，不需要 root，也不需要电脑。

本地运行
只把模型请求送出

以 proot 运行 Ubuntu 22.04 arm64，通过 OneBot v11 连接 QQ，再调用 OpenAI 兼容或 Anthropic 模型接口。

No root / No server
Android 7.0+ ARM64 OneBot v11 5.9 MB APK
01

定位

把一台 Android 手机变成一个本地运行的 QQ AI 节点。

01 / LOCAL

全部在手机内

Ubuntu、QQ NT、NapCat 和历史上下文存放在 App 私有目录。

02 / SIMPLE

不需要 root

用 proot 提供用户态 Linux 环境，普通应用权限即可运行。

03 / OPEN

接口自由选择

支持 10 家厂商预设，也支持任意 OpenAI 兼容中转地址。

02

系统

一条消息从 QQ 进入，经过本地编排，再由模型返回。

01 / IN
QQ NT→NapCat→OneBot
02 / LOCAL
127.0.0.1:3001→B-bot App→本地历史
03 / OUT
LLM Client→模型 API→回复 QQ
